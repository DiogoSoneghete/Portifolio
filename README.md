## 🚀 Como Executar o Projeto

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento (Hot-Reload)
npm run dev

# 3. Gerar a build otimizada para produção
npm run build

# 4. Pré-visualizar a build de produção localmente
npm run preview
```
